# Weekly Recording Kit

One sitting, once a week, ~20-30 minutes. You read 7 scripts into your phone. Everything after that is pipeline, not you.

---

## THE SESSION

**Where:** your car, parked, engine and AC off (AC kills the mic). Same spot every week — dash-mounted phone, because it's the one location you're actually in every single week regardless of what you're working on, and it's already the proven setup in `scripts/SELFIE-VIDEO-WORKFLOW.md`. If you'd rather do the shop, that works too — pick one and stay with it so the feed looks consistent, not like 7 different sets.

**Checklist, glance at this before you hit record:**
- [ ] Vertical (9:16), NOT horizontal
- [ ] Phone at eye level, not propped low shooting up your chin
- [ ] Facing the light (window/sun), never backlit
- [ ] Phone 8-12 inches from your mouth
- [ ] AC / dust collector OFF
- [ ] Dark solid top, button-up if you've got one on

**Recording rule:** one take per script. Read it through once. If you badly flub it, one re-do, max two takes total — then move on. Don't rewatch and don't chase a "better" take. The whole point of this kit is that hesitation costs you the 20-30 minutes back.

**Order:** read all 7 back to back, phone stays mounted the whole time. Say the script number out loud before each one ("one," "two"...) so whoever sorts the raw file later can find the cut points fast.

## WHAT HAPPENS AFTER YOU RECORD — the exact handoff

**Step 1 — you.** Export or send the raw takes to Claudy (Telegram) same as the existing selfie workflow, or just save straight to the phone/PC folders above if you're already at your desk. Say "DONE" in Telegram when the week's batch is in.

**Step 2 — captions (you or me, Submagic is manual-upload only, $12/mo plan, no API).** Open Submagic, upload each take, tap Auto Captions (Bold/Spotlight template), tap Auto B-Roll, export 9:16. Save the export using the exact filename above, into the right folder.

**Step 3 — queueing the Dossie clips (me, one command).**
```
python scripts/queue-finished-videos.py
```
This scans `Media/finished-videos/`, uploads to Supabase Storage, and inserts a `video_library` row per file with `status='approved'`.

**Two things in this script are NOT built for a clean weekly drop and I have to work around them every week until Carter fixes them:**
1. **It only ingests 5 specific hardcoded filenames from a May batch (`TARGET_STEMS` in the script) — it will silently skip anything new, including this week's clips.** Real fix: Carter deletes the `TARGET_STEMS` allowlist so it queues any `.mp4` not already in the DB (the "already in DB" check already exists in the script, it's the filter on top of it that's the problem). Until that ships, I'll do a one-off Supabase upsert per file instead of relying on the scanner.
2. **The caption it auto-generates always appends "meetdossie.com/founding" — founding is closed, so that caption is wrong.** After queueing, I PATCH each row's `caption` field to the one written above instead of trusting the auto-generated one.
3. **Selfie clips default to `platforms: ["tiktok","instagram"]` only, no Facebook** — Meet Dossie's FB Page is a real channel, so I PATCH `platforms` to add `"facebook"` on each row.

**Step 4 — Telegram approval (you, one tap each).** `cron-post-videos.js` runs daily, finds any `status='approved'` row, and sends it to you via DossieMarketingBot for Approve/Reject. Tap Approve on each of the 4.

**Step 5 — posting (automatic, but watch queue depth).** Once you approve, the row becomes `heath_approved`. `cron-post-videos.js` posts the **oldest** `heath_approved` row, one per day, across the platforms on that row. If there's an existing backlog of approved screen-demo videos ahead of your fresh clips (there usually is, per `docs/FEATURE-VIDEO-DAILY-PLAN.md`), your new selfie content will queue behind it and post later in the week than you'd want. I'll flag this to you each week and can bump the fresh clips to the front if needed — just say so.

**Step 6 — realtor clips (NOT an automated pipeline today — flag this honestly).** `video_library` / `cron-post-videos.js` is hardcoded to MeetDossie's own "dossie" Zernio accounts. It never posts to your realtor Facebook/Instagram, no matter what's in the row. So the 3 realtor clips do **not** go through Steps 3-5 at all. Today's real path: I post them directly through the Zernio dashboard to your "Brokerage" profile (Facebook `facebook.com/HeathShepardRealtor`, account id `6a8469f177555aae01775798`; Instagram `@heathshepardrealtor`, account id `6a8469d677555aae017735a1`) after you approve the caption over Telegram. The cleaner long-term fix — flagging for Carter, not building now — is a `queue-realtor-video.py` that inserts a `social_posts` row with `target_owner='heath-realtor'` and a real `media_url`, so it rides the existing `cron-publish-approved.js` pipeline (which already supports `target_owner` + `media_url`) instead of a manual Zernio upload every week.
